# Voxel HD — воксельный HD-пакет для Minecraft Bedrock

Ресурспак, который превращает ванильный Bedrock в «воксельный» с повышенной детализацией.
Всё собирается скриптом из оригинальных ресурсов Mojang, поэтому пак можно пересобрать
под любую версию игры.

Готовый файл: [`dist/VoxelHD.mcpack`](dist/VoxelHD.mcpack) — откройте его, и Minecraft сам импортирует пак.

## Что внутри

| Часть | Что делает | Масштаб |
|---|---|---|
| HD-текстуры | Каждый тексель остаётся квадратным вокселем, разрешение ×4 (16 → 64 px). Яркость текселя задаёт высоту: светлее — выступает, темнее — утоплено, свет сверху-слева. | блоки (1248), предметы (910), мобы (716), броня (23) |
| Рельеф для Vibrant Visuals | Для непрозрачных блоков и блоков с жёстким вырезом генерируется карта высот на 6 уровней (1128 блоков). Ванильные карты MERS сохранены и увеличены, поэтому руды, лава и факелы светятся как раньше. | 2831 texture set |
| 3D-предметы в руке | Для 258 предметов (мечи, кирки, еда, слитки, самоцветы…) спрайт превращён в воксельную модель: сетка 0,5 ед., толщина 1,5 ед. (в ваниле 1). Сглаживание ступенек — Scale2x. | 258 attachable |

Превью: [`preview/textures_before_after.png`](preview/textures_before_after.png) (сверху оригинал, снизу Voxel HD),
[`preview/voxel_items.png`](preview/voxel_items.png) (воксельные предметы).

## Установка

1. Нужен Minecraft Bedrock 1.21.30 или новее.
2. Откройте `VoxelHD.mcpack`.
3. Настройки → Глобальные ресурсы → активируйте **Voxel HD**.
4. Для настоящего рельефа включите **Vibrant Visuals** (Настройки → Видео → Графика). Без него остаётся HD-вид с воксельной подсветкой, но без параллакса.

## Чего этот пакет не может (ограничения платформы)

Ресурспак Bedrock **не может менять форму ванильных блоков**, поэтому блоки остаются кубами.
Воксельность блоков достигается текстурой и картой высот.
Предметы в инвентаре и на земле остаются плоскими иконками (HD-иконки), потому что ресурспак меняет только модель в руке.
Мобы получили HD-текстуры, но **не перемоделены**: их геометрия не изменена.

## Что не проверено в игре

Файлы проходят структурную проверку (`tools/validate.py`: JSON, ссылки texture set, размеры карт, attachable → геометрия),
но **в самой игре пак не запускался**. Особенно это касается 3D-предметов в руке:

- Поза взята у ванильного лука (`animation.bow.wield` + те же `position/rotation/local_pivot`). Мечи и кирки в игре могут сидеть в руке чуть иначе, чем стандартные.
- Толщина задаётся полями `scale[1]` и `use_pixel_depth: false`. Если игра их игнорирует, предмет будет тоньше, но останется воксельным.
- Если что-то выглядит криво, правьте константы в начале `tools/build.py` (`ITEM_THICKNESS`, `K`, `LEVELS`, `RELIEF`) и поворот в `build_items()`, затем пересоберите.

## Пересборка

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/Mojang/bedrock-samples.git
cd bedrock-samples && git sparse-checkout set --no-cone /resource_pack
python3 voxel_hd/tools/build.py bedrock-samples/resource_pack out/VoxelHD_RP
python3 voxel_hd/tools/validate.py out/VoxelHD_RP
(cd out/VoxelHD_RP && zip -qr -9 ../VoxelHD.mcpack .)
```

Требуется Python 3, Pillow и NumPy. Превью воксельных предметов: `tools/preview_items.py`.

## Что можно сделать дальше

- Перемоделировать мобов в воксели с рельефом (геометрия `.geo.json` с разбиением кубов и сохранением имён костей, чтобы анимации работали).
- Подпаки с разным разрешением (32×/64×/128×) для слабых устройств.
